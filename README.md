# 🌱 Marutham - Smart Agriculture Management Platform

## Overview

Marutham is a comprehensive agriculture management platform designed to empower farmers, agricultural experts, and stakeholders through digital transformation. The platform provides tools for market price tracking, soil health monitoring, equipment sharing, agricultural consultations, and community collaboration to improve farming productivity and decision-making.

## Key Features

### 🌾 Farmer Community Platform

* Create and manage agricultural posts
* Like and comment on community discussions
* Share farming knowledge and best practices
* Receive notifications for important activities

### 📈 Market Intelligence

* Real-time market price tracking
* Crop price request management
* Market trend analysis support
* Better decision-making for crop sales

### 🌱 Soil Health Management

* Soil report generation and storage
* Soil analysis tracking
* Recommendations for improved productivity

### 🚜 Equipment Management

* Agricultural equipment listing and management
* Equipment request workflow
* Resource sharing among farmers

### 👨‍🌾 Expert Consultation

* Connect farmers with agricultural experts
* Consultation request management
* Digital advisory support

### 🔒 Security and Performance

* Authentication and authorization mechanisms
* CSRF protection
* Rate limiting implementation
* Input validation and error handling
* Activity logging and auditing

## Project Architecture

The application follows a layered architecture pattern:

* **Controller Layer** - Handles HTTP requests and responses.
* **DAO Layer** - Manages database interactions.
* **Model Layer** - Represents business entities.
* **Utility Layer** - Provides reusable helper functions and security components.

## Getting Started

### Prerequisites

* Java 17+
* Apache Tomcat
* MySQL 8+
* Maven

### Installation

```bash
git clone <repository-url>
cd Marutham
```

Configure database credentials and deploy the application to your servlet container.
